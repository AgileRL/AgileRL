Training PPO on a Custom Environment in Arena
=============================================

.. note::

   This tutorial has been retired. Arena no longer trains classic RL algorithms such as PPO,
   DQN or TD3, so the custom-environment workflow it described no longer runs there.

To train PPO, or any other classic RL algorithm, on your own environment, use open-source
AgileRL on your own machine or cluster: start with the :ref:`Gymnasium tutorials <Gymnasium_tutorials>`,
or install the `AgileRL v2 release <https://github.com/AgileRL/AgileRL/releases/tag/v2.67.0>`_.

Arena trains and serves LLMs. See :doc:`Training on Arena <index>` for the GRPO tutorials.
